# Global Malaria 1990-2019: MDG Analysis

**Tools:** Python, Excel, Power Query, Pivot Tables, Charts  
**Data Source:** Institute for Health Metrics and Evaluation, Global Burden of Disease (2019)  
**Date:** 2026

### Project Goal
Evaluate progress toward UN Millennium Development Goal 6: Combat HIV/AIDS, malaria, and other diseases. Focus on malaria trends from 1990-2019 across 190+ countries.

### Key Findings
1. **27% reduction** in confirmed malaria cases globally by 2015 vs 2000 baseline
2. **37% drop** in malaria incidence rate per 1,000 population at risk
3. **Africa burden:** Region still accounted for ~90% of global cases in 2019
4. **Target missed:** World Health Assembly 50% reduction goal for 2015 not achieved

- Interactive country filter with slicers
