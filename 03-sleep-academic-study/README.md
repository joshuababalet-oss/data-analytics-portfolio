# Effect of Sleep on Academic Performance

**Role:** Project Lead & Data Analyst  
**Type:** Undergraduate Research Project, Sa'adu Zungur University  
**Team Size:** 4 students  
**Tools:** Google Forms, Excel, Python 
**Data:** 200+ survey responses from Basic Medical Science students  
**Date:** 2024

### Project Goal
Investigate the relationship between sleep duration and cumulative GPA among medical students.

### My Contributions
1. **Survey Design:** Created Google Forms questionnaire, defined variables, managed response collection
2. **Data Pipeline:** Exported responses to Excel, coded categorical data, handled missing values
3. **Analysis:** Ran descriptive statistics + correlation test in Excel to test sleep vs CGPA hypothesis  
4. **Reporting:** Wrote methods/results sections and presented findings to Faculty of Basic Medical Sciences

### Key Findings
- Students sleeping <7 hours/night had **lower average CGPA**
- **Significant relationship** found between sleep duration and academic performance p<0.05
- Recommended sleep hygiene awareness program for students
